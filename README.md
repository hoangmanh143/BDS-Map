# Bản đồ giá căn hộ TP.HCM

Trang bản đồ giá chào bán căn hộ TP.HCM (Leaflet + OpenStreetMap), cập nhật hằng tuần, kèm bộ agent Claude để thu thập, phân tích và cập nhật dữ liệu.

- `docs/`: trang web tĩnh (GitHub Pages: Settings → Pages → Deploy from branch → `main` / `/docs`).
- `bds/agents/`: script của 5 agent (thu thập, phân tích giá, tin quy hoạch, bản đồ, cập nhật hằng tuần).
- `.claude/skills/`: kỹ năng Claude tương ứng. `CLAUDE.md`: bối cảnh dự án.
- Cài đặt và chạy: xem `HUONG_DAN_CAI_DAT.md`.

Giá hiển thị là giá chào bán trên tin đăng, không phải giá giao dịch.
